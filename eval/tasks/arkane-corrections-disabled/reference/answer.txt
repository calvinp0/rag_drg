No. With AEC and BAC disabled the absolute H298 values are not meaningful (relative barriers/kinetics are still fine). The level has no Arkane atom energy corrections, so fit them first with the group's AEC/BAC templates (knowledge/arc/templates/aec_bac): set LEVEL in aec_bac_common.py, run write_arc_input.py, run ARC (sp only on the 16 reference species at CCCBDB geometries), then fit_aec.py (AEJob) and put the AECs into RMG-database quantum_corrections/data.py. Rerun Arkane; optionally fit BACs with bac_write_arc_input.py, fit_bac.py and run_bac_fit.py.
