# Gaussian 09 vs Gaussian 16

The authoritative list is Gaussian's release notes page (https://gaussian.com/relnotes/?tabid=1),
which is configured as a web source (`gaussian-keywords` in `rag_drg.yaml`). Enable and fetch it
to index the full list. This card holds only the differences that most often bite.

## Default integration grid (changes energies)

* G16 default: `Int=UltraFine`. G09 default: `FineGrid`.
* Consequence: the same route gives slightly different DFT energies and, for meta-GGAs
  (M06-2X etc.), sometimes different geometries/frequencies. When comparing to or continuing
  G09 work in G16 (or the reverse), set the grid explicitly in both (`Int=UltraFine`).

## Parallel and GPU Link0 commands

* `%cpu=0-15` (pin specific cores) and `%gpucpu=gpu-list=control-cpu-list` exist in G16 only.
  G09 inputs use `%nprocshared=N` (also valid in G16).
* GPU acceleration exists only in G16 GPU builds (HF/DFT energies, gradients, frequencies).

## Reproducibility checklist when mixing versions

* Record the exact version and revision from the output header (e.g. `Gaussian 16, Revision C.01`);
  ARC records it in `output.yml` (`ess_versions`).
* Pin grid, SCF convergence and dispersion explicitly instead of relying on defaults.
* Do not mix G09 and G16 energies inside one reaction energy / barrier.
