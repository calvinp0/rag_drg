# Papers

Put project literature here as `papers/<project>/<first-author><year>-<short-title>.pdf`.
PDFs are **git-ignored** (copyright). Share them through the group drive, and have each
member (or the shared server) keep a local copy here before running `rag-drg ingest`.

What *is* committed: `papers/<project>/notes.md` with the key takeaways, equations and
settings from each paper. Notes are small, reviewable, and rank well in search.
